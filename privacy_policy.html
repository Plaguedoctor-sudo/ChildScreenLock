Privacy Policy for Child Screen Lock

Effective Date: October 4, 2026
Last Updated: October 4, 2026

Core Privacy Commitment: Child Screen Lock is strictly air-gapped and requests NO INTERNET PERMISSION. No user data, device identifiers, or biometric profiles are ever collected, transmitted to remote servers, or shared with third parties.

1. Summary & Scope

Child Screen Lock is an assistive parental control tool engineered to help parents and authorized legal guardians manage screen time and limit access to unapproved apps on personal Android devices.

2. Facial Biometrics & Camera Data (Children's Privacy Protection)

To detect when a child is holding or interacting with the device, the app utilizes camera frames solely for local geometric comparison:

  • On-Device Machine Learning: Camera frames are analyzed locally in real time using on-device ML models.
  • No Photo Storage: We never capture, store, or transmit raw photos, video clips, or camera feeds.
  • Hardware-Encrypted Embeddings: Facial landmark geometry is converted into a 128-dimensional mathematical vector encrypted via the hardware-backed Android KeyStore (AES-256-GCM).
  • Zeroization: Parents can delete and permanently zeroize all biometric data with a single tap in the Settings menu.

3. Android Accessibility Service API Disclosure

In accordance with Google Play Accessibility Service policies, Child Screen Lock uses the AccessibilityService API exclusively for the following purpose:

  • Purpose: To observe the package name of the active foreground application. When an unapproved app is launched during an active screen time restriction session, the service navigates the device back to the home screen.
  • Data Protection: The service does not read text input, monitor keystrokes, track passwords, inspect notifications, or access content inside applications.

4. Android VpnService (Local Telemetry & Tracker Blocker)

Child Screen Lock operates a strictly local loopback VPN using Android's VpnService API:

  • Local DNS Sinkhole: All network traffic remains on the physical device (loopback). The service intercepts standard DNS queries on UDP 53 to drop queries intended for known advertisement, telemetry, and tracking endpoints (sinkholing them to 0.0.0.0).
  • No External Tunneling: Traffic is never redirected to remote servers or third-party proxies.

5. Security & Anti-Brute-Force Safeguards

  • PIN Derivation: Parent authorization PINs are safeguarded using salted, memory-hard key derivation (scrypt/PBKDF2).
  • Anti-Tamper & Progressive Lockout: Rapid repeated attempts trigger progressive exponential lockouts to defeat PIN-spray attacks.
  • Master Recovery Key: Secure offline recovery key provided directly to parents for emergency uninstallation or PIN recovery.

6. Children's Privacy (COPPA & GDPR)

The application complies fully with COPPA and GDPR regulations. Because the software contains no analytics, ad SDKs, or cloud backends, no personal data from minors is collected, stored remotely, or sold.

7. Contact

For inquiries regarding this policy or the application's local security architecture, please contact the developer via the official developer email listed on the Google Play Store.
